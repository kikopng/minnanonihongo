# 🌸 Minna no Nihongo Interactive Learning

A lightweight, client-side web application designed to help beginners master Japanese vocabulary, alphabets, and grammar through interactive game-based exercises.

[![Live Demo](https://remarkable-brioche-ac4d57.netlify.app/exercise?lesson=1)

---

## ✨ Features

* **🎮 Gamified Practice:** Turns traditional drills and quizzes into interactive mini-games to boost engagement and retention.
* **📚 Progressive Lessons:** Structured lesson routing starting from Lesson 1, allowing learners to progress step-by-step at their own pace.
* **⚡ Instant Feedback:** Dynamic validation provides immediate correctness checks so users can learn from mistakes on the spot.
* **📱 Responsive Design:** Optimized for smooth practice sessions on both desktop and mobile web browsers.

---
